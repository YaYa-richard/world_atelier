# 观隅 · 世界观工作台

双击 index.html 即可使用，无需安装。建议固定使用同一个浏览器打开同一路径。

- 六类档案：人物、地点、物品、势力、设定、正文。
- 新建、编辑、删除、标签筛选、全文检索（Ctrl/Cmd+K）。
- 正文使用 [[沈照夜]] 形式引用词条，点击打开信息弹窗；弹窗显示反向引用。
- 修改档案名称时自动更新已有正文引用。
- 数据存于浏览器 localStorage；请定期导出 JSON 备份。清理浏览器数据、换浏览器或设备不会自动迁移。
- 导入会替换全部档案，并会要求确认，请先备份。
- 首次打开含可编辑的示例世界「雾海纪事」。

当前为单机原型，没有账号、云同步、多人协作或富文本编辑。属性通过正文中的「身份：」「能力：」等文本记录，尚非独立属性字段。字体联网加载，离线使用会自动回退系统字体。

验证：node --check app.js。尚未执行浏览器交互自动化测试。
